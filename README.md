# Prime Propo

**Prime Propo** is a proportional variant of [Courier Prime Sans](https://github.com/quoteunquoteapps/CourierPrimeSans "Courier Prime Repository"), the classic monospaced font designed specifically for screenplays. 

While the original Courier Prime keeps every character at a fixed width as it is a recreation, **Prime Propo adjusts character spacing proportionally** for enhanced legibility, smoother reading, and tighter document text layouts, all while retaining that nostalgic, elegant typewriter aesthetic for the sans-serif folks.

## ✨ Features

* **Proportional Spacing:** Optimized kerning and varying character widths for standard document reading rather than strict monospaced grids.
* **Courier Prime Sans Heritage:** Retains the beautiful, screen-optimized weight, counters, and terminals of the original design by Alan Dague-Greene.
* **Perfect for:** Creative writing, correspondence, coding (if you, for some reason, prefer proportional fonts), or any design seeking a typewriter feel without monospaced constraints.

## 📥 Installation

### 1. Download the Fonts
Go to the releases page and download the compiled font binaries (`.ttf` or `.otf`).

### 2. Install on Your System
* **macOS:** Double-click the downloaded file and click **Install Font** in the Font Book app.
* **Windows:** Right-click the file and select **Install** (or *Install for all users*).
* **Linux:** Move the font files to `~/.local/share/fonts` or `/usr/share/fonts` and run `fc-cache -f -v`.

## 🛠 How This Was Created

I took Courier Prime Sans and started making tweaks to it, like decreasing the spacing of the letters, making the M m W w wider, using the ij digraph/ligature to change the i and j, adding kra, and renaming it.
